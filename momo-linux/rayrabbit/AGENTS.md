# Contrato para agentes IA que trabajen en Mo Mo Mummy

1. Escribir primero una especificacion y una prueba que reproduzca el defecto (RED); documentar la correccion y su prueba GREEN.
2. Toda alteracion de credito, billetero, transacciones, bonus, jackpot, servidor, RTP o kiosko requiere revision especifica.
3. Nunca eliminar protecciones de persistencia para lograr un PASS; no reconocer un ACK antes de una escritura durable.
4. Prohibido copiar el juego, ZIPs, licencias, secretos o registros de credito a un repositorio publico.
5. Conservar KIOSKO V11 de arranque simple; no regresar a Shell Launcher.
6. No reemplazar un estado corrupto por saldo cero silenciosamente; bloquear transacciones y mantener evidencia.
7. Cada prueba debe informar su resultado real; separar tests seleccionados, tests historicos y pruebas fisicas no realizadas.
8. Los cambios a maquinas Windows LTSC requieren autorizacion y plan de reversión; este repo no instala nada.
